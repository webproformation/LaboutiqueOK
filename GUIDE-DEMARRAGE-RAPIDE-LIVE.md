# 🚀 Guide de Démarrage Rapide - Premier Live

**Temps total estimé : 30 minutes**

---

## ⚡ Checklist Express

### Avant le live (15 min)

#### 1️⃣ Configuration OBS (une seule fois)
```
☐ Télécharger OBS Studio → obsproject.com
☐ Installer le logiciel
☐ Aller sur /admin/lives/obs-settings
☐ Copier l'URL du serveur
☐ Copier la clé de stream
☐ Dans OBS → Paramètres → Stream → Custom
☐ Coller URL et clé → OK
```

#### 2️⃣ Créer le live (5 min)
```
☐ Aller sur /admin/lives/new
☐ Titre : "🔥 Test live - Présentation collection"
☐ Date/heure : Maintenant + 10 minutes
☐ Activer : Chat ✓ | Produits ✓ | Enregistrement ✓
☐ Cliquer "Créer le live"
```

#### 3️⃣ Préparer votre scène OBS (10 min)
```
☐ Ajouter source : Caméra
☐ Ajouter source : Micro
☐ Tester le son et l'image
☐ (Optionnel) Ajouter logo/overlay
```

---

### Pendant le live (30-45 min)

#### Démarrage (2 min)
```
☐ Aller sur /admin/lives
☐ Trouver votre live
☐ Cliquer "Démarrer"
☐ Dans OBS → "Démarrer le streaming"
☐ Attendre 5 secondes → Vous êtes EN DIRECT ! 🔴
```

#### Animation (20-30 min)
```
☐ Accueillir : "Bonjour à tous ! Bienvenue !"
☐ Présenter : "Aujourd'hui je vous présente..."
☐ Partager produits :
   → Ouvrir /admin/lives/[id]
   → Onglet "Produits"
   → Rechercher → "Partager"
☐ Interagir chat :
   → Onglet "Chat"
   → Lire messages à voix haute
   → Répondre aux questions
```

#### Clôture (5 min)
```
☐ "Merci à tous d'avoir suivi ce live !"
☐ "N'oubliez pas les offres exclusives"
☐ "Rendez-vous la semaine prochaine"
☐ Cliquer "Terminer" dans /admin/lives
☐ Dans OBS → "Arrêter le streaming"
```

---

### Après le live (10 min)

#### Analyse
```
☐ Onglet "Statistiques"
☐ Noter le nombre de spectateurs max
☐ Vérifier les produits les plus cliqués
☐ Lire les derniers messages chat
```

#### Communication
```
☐ Remercier via email/réseaux sociaux
☐ Partager le replay
☐ Annoncer le prochain live
```

---

## 💡 Conseils Pro

### Pour un live réussi

✅ **DO :**
- Sourire et être naturel
- Montrer les produits sous tous les angles
- Lire les noms des spectateurs
- Créer de l'urgence (offres limitées)
- Interagir avec le chat régulièrement
- Préparer un script léger

❌ **DON'T :**
- Lire un texte mot à mot
- Ignorer le chat
- Faire des lives de +1h au début
- Oublier de tester le son avant
- Paniquer si un bug survient

## 🆘 En cas de problème

### Le live ne démarre pas
```
1. Vérifier la connexion internet
2. Vérifier que la clé de stream est correcte dans OBS
3. Redémarrer OBS
4. Contacter le support si ça persiste
```

### Personne ne vient
```
1. Normal pour le premier live test
2. Inviter des amis/famille pour débuter
3. Annoncer 24h à l'avance sur les réseaux sociaux
4. Envoyer un email à vos abonnés
```

### Le chat est vide
```
1. Poser des questions directes
2. "Qui me regarde de Paris ? 👋"
3. "Mettez un ❤️ si vous êtes là"
4. Annoncer un cadeau pour le premier commentaire
```

### Problème technique
```
1. Rester calme et sourire
2. "On a un petit souci technique, on revient dans 2 min"
3. Vérifier OBS et la connexion
4. Reprendre le live tranquillement
```
